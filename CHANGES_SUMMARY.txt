================================================================================
KEY FEATURES IMPLEMENTED
================================================================================

1. NVIDIA PHYSICS ALGORITHM WITH SOFTENING
   - Added softening parameter (epsilon = 0.01f)
   - Force: F = G * m_i * m_j * r / (r^2 + epsilon^2)^(3/2)
   - Prevents singularities when particles are close
   - Matches NVIDIA CUDA nbody sample implementation

2. MOUSE CAMERA CONTROL
   - Drag mouse to rotate camera (like NVIDIA sample)
   - Horizontal drag → yaw rotation (Y-axis)
   - Vertical drag → pitch rotation (X-axis)
   - Sensitivity: 0.005 radians per pixel
   - Vertical angle clamped: -1.5 to 1.5 radians

3. SMOOTH CAMERA TRACKING
   - Press 'C' to toggle tracking mode
   - Exponential smoothing (10% of remaining distance per frame)
   - Target: angle_x=0.3, angle_y=0.0, dist=50.0
   - Auto-centralizes particles around center of mass
   - Manual controls disable tracking

4. PARTICLE SIZE UI CONTROL
   - Green slider for size adjustment
   - Range: 5.0 to 40.0 (default: 15.0)
   - Real-time adjustment during simulation
   - Position: y=65-80, x=320-720

5. ENHANCED UI
   - Two sliders:
     * Yellow: Simulation speed (0-2x)
     * Green: Particle size (5-40)
   - Camera tracking status indicator
   - Updated help text
   - Better layout organization
